## Dependency behavior that must not be guessed
[ArmatureInstance pinned source](https://github.com/vpenades/SharpGLTF/blob/1.0.0-alpha0031/src/SharpGLTF.Runtime/Runtime/ArmatureInstance.cs) normalizes supplied weights. [AffineTransform.Blend pinned source](https://github.com/vpenades/SharpGLTF/blob/1.0.0-alpha0031/src/SharpGLTF.Core/Transforms/AffineTransform.cs) returns a sole transform even at weight zero. For multiple tracks, S/T use direct normalized weights, while quaternion accumulation calls Slerp(current, accumulated, currentWeight/cumulativeWeight). OG supplies reverse-ordered tracks with `1-Blend`; that exact ordering and weighting—not a generic skeleton lerp—is exercised against actual clip poses by `animated_joint_pose_parity_smoke.py`.
