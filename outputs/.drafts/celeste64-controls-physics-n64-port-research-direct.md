## Key findings (synthesis input)

1. **Constants are already 1:1 with OG.** movement_config.hpp carries every OG constant with the OG value. The port is NOT a re-derivation — it's a direct translation. The remaining work is behavioral parity + missing subsystems, not re-tuning.
2. **The single mover is ported.** MoveService = OG SweepTestMove + Popout + GroundCheck/CeilingCheck/GroundSnap/CancelGroundSnap, with the documented +Y-up feet-anchored conversion. Climb uses a waist-only SweepMoveClimb (deliberate deviation for sloped baked walls).
3. **State machine is hand-switched, not a real FSM.** OG uses StateMachine<States,Events>; the port switches on PlayerMovementState enums inside StatePhase. The gap matrix lists "state machine (missing)".
4. **Input layer gap:** OG uses Foster VirtualStick (0.35 deadzone) + VirtualButton (0.1s buffer) with consume-once semantics. The port HAS virtual_input.hpp/cpp (deadzone + buffer + consume) but the live InputSystem reads raw joypad directly into InputActionVec2/InputButton — the virtual layer is not wired. Jump/dash buffering is re-implemented inside the controller (jump_buffer_remaining, dash_buffer_remaining) rather than in the input device.
5. **Camera deviations:** zoom_rate 1.8 vs OG 1.0, zoom_snap_speed 1.0 vs OG 0.5 (documented, deliberate for stick medium). Orbit 4 rad/s, follow decay, FOV map (76.8→120 → 1→1.2) are OG-exact. Camera near plane 5 (N64 renderer) vs OG 0.01.
6. **Missing subsystems (not ported):** Feather (FeatherStart/Feather states), Spring (SpringActor exists in actor/ but the player Spring() handler parity?), StrawbGet, Respawn/Dead states, Bubble, Cassette, cutscene, NPC interaction, breakable blocks, spike/DeathBlock overlap checks, moving-solid rider propagation (PlatformCarryState exists but partial), ledge-avoid sweep (d=4) in StNormalUpdate, dust/footstep audio, dash trails, hair color states.
7. **Climb parity is deep but has documented deviations:** facing-dot gate M2 (OG never dot-gates), mantle 2-tick confirm (OG instant), entry probe radius 5 vs OG 4, waist-only climb popout (sloped-wall fix), neutral walljump split 105/40 (demake-tuned).
8. **The grab-entry front-side gate tension** (from the previous session): the gate rejects reversed-winding baked walls; removing it re-enables auto-latch. The proper fix is a winding-independent front-side test (oriented normal), parked.
9. **Verification infrastructure is strong:** 57 host smokes + climb_bug_probe + device capture_baseline + [memory]/[climb] telemetry. The feel acceptance doc lists the manual ROM checks.
10. **Online refs confirm:** canonical repo (MIT source), itch page (controller recommended), ControlsConfig defaults (Jump=South/North, Dash=West/East, Climb=shoulders+triggers, Move/Camera deadzone 0.35).
